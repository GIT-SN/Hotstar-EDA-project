# Hotstar-EDA-project
Exploratory data analysis of streaming content ,engagement and drop-off patterns using Python.

## Dataset Disclaimer

This project uses the **OTT Viewer Drop-Off & Retention Risk Dataset**, containing approximately 33,200 episode-level records with engagement-related variables such as watch percentage, pauses, rewinds, intro skipping, cognitive load, drop-off probability, and retention risk.

**The dataset is synthetically generated for realistic OTT analytics. It is not actual Hotstar proprietary data.** Hotstar is used as the business scenario to explore viewer engagement, retention patterns, and potential drop-off behaviour.

All findings reflect patterns within this synthetic dataset and should not be interpreted as real-world Hotstar user behaviour.
